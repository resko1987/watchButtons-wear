<!-- English -->
Watch Buttons — a paired Android + Wear OS app that lets you control your phone's and watch's sound from a single tap, and fire HTTP GET/POST requests to any URL from customizable buttons.

Features:
- One-tap sound modes: Do Not Disturb, Vibration only, Normal mode — applied on both phone and watch from either device
- Custom buttons with configurable URL or IP, GET/POST method and JSON request body
- Double-tap action: assign a second action (e.g. single tap turns the light on, double tap turns it off)
- Long-press to edit or delete any button
- Button layout options: 1, 2 or 3 per row, or centered; adjustable button colors
- Buttons and settings sync automatically between phone and watch via the Wearable Data API
- Multi-language UI: English, Russian, Chinese (easily extensible)
- All data stored locally — no server, no accounts

<!-- Русский -->
Watch Buttons — связка приложений Android + Wear OS: одним нажатием управляй звуком телефона и часов и отправляй HTTP GET/POST запросы на любые адреса через свои кнопки.

Возможности:
- Режимы звука в одно касание: «Не беспокоить», «Только вибрация», «Обычный режим» — применяются на телефоне и часах из любого приложения
- Свои кнопки: настраиваемый URL или IP-адрес, метод GET/POST, тело JSON-запроса
- Двойное нажатие: второе действие (например, один клик включает свет, двойной — выключает)
- Долгое нажатие — редактирование или удаление кнопки
- Раскладка кнопок: 1, 2 или 3 в ряд, либо по центру; настраиваемый цвет кнопок
- Кнопки и настройки автоматически синхронизируются между телефоном и часами через Wearable Data API
- Интерфейс на трёх языках: английский, русский, китайский (легко расширяемый)
- Все данные хранятся локально — без серверов и аккаунтов
